# Bodhi Hotels & Resorts — Kumbhalgarh Travel Guides

A responsive, mobile-friendly travel and hospitality content website for Bodhi Hotels & Resorts in Kumbhalgarh, Rajasthan.

## Website URLs

- Repository: https://github.com/bidhihotels/bodhi-hotels-resort-guides
- GitHub Pages (expected): https://bidhihotels.github.io/bodhi-hotels-resort-guides/
- Official hotel website: https://www.bodhihotels.in/

## Properties covered

1. [Collective Hotels Bodhi](https://www.bodhihotels.in/collective-bodhi/) — dome glamping, planet-inspired dome categories, mountain-view stays, Taramandal, Bar - Chuski, Zen Lounge, mini-lake and game zone.
2. [Bodhi Boutique By Collective Select](https://www.bodhihotels.in/bodhi-boutique/) — Deluxe Rooms, Super Deluxe Rooms, Suite Rooms, Lumbini Restaurant, Tara terrace café, pool and event lawn.

These are separate properties. Room types and facilities are not combined. Always confirm current room details, amenities, availability, rates and booking conditions with the relevant property.

## Technical features

- Static HTML, CSS and lightweight JavaScript; compatible with GitHub Pages.
- Responsive layout and navigation.
- Unique page titles and meta descriptions.
- Canonical URLs and Open Graph metadata.
- Article JSON-LD on all ten articles.
- XML sitemap and robots.txt.
- Descriptive headings, image alt text where images are used, and internal links.
- Official property links for current hotel details and reservations.

## Publishing

The repository is configured for GitHub Pages using the existing Pages deployment workflow. Check **Settings → Pages** and the **Actions** tab for the latest deployment status. If Pages is set to deploy from a branch, select `main` and `/(root)`; if it is set to GitHub Actions, keep the Pages workflow enabled.

## Editorial and image policy

Editorial copy is written for this guide and is not copied as full articles from the official website. Property images are referenced from official Bodhi website image paths. The official hotel website remains the source for live booking information.
